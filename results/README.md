# results/

Measured outputs only, as `results/Mxx/<ds>/*.json`, written by scripts. Each file records the git SHA, dataset, config and timestamp.

Numbers in `docs/results.md`, the README and chat summaries come from files here and nowhere else. If something has not been measured, write "TBD (not measured)".

Raw data stays out: `results/**/raw/` is gitignored.
